## Production notes

**Audio:**
- Every narration line generated via `/api/tts` with `voice: "bf_emma"` (Chloe's production voice).
- Kokoro output is peak-normalised to -3dBFS per production TTS route.
- Final track normalised to -16 LUFS (broadcast spec) post-generation via ffmpeg loudnorm.
- 500ms fade-in at scene start, 300ms fade-out at scene end for ambient breathing room.

**Video:**
- Source screenshots captured at 2× DPI via Playwright against `lucentra.app` authenticated session.
- Output render: 1920×1080, 30fps, H.264, MP4 container, ~15 MB final file size.
- Ken Burns motion via ffmpeg zoompan filter with easing curves.
- Cross-fades between scenes: 500ms.

**Branding:**
- Lucentra wordmark bottom-right throughout, 0.6 opacity, 40px height.
- Caption text in Inter, 24px, white with 0.4 opacity black backdrop (accessibility).
- No background music (copyright + clarity).

**Quality checkpoints before publication:**
- [ ] Every on-screen metric matches a real production surface at the scene's capture timestamp.
- [ ] No placeholder text visible (no "Loading..." or skeleton states leaked).
- [ ] Chloe's voice continuous across scene cuts (no abrupt pitch changes).
- [ ] Captions readable on mobile viewport (tested via 375px-wide preview).
- [ ] Close scene 15 syncs the final "Both." word to the Lucentra wordmark reveal frame.

## Rule 43 flags

1. **Voice consistency across regeneration.** Kokoro `bf_emma` voice is deterministic per-input but differs across Kokoro-server version bumps. Capture a checksum of the Kokoro server version used + save with the render. Any future regeneration that produces audibly different output = server drift; re-test.

2. **Authenticated screenshot capture requires a live test session.** Uses the existing `LUCENTRA_TEST_SESSION` GitHub secret (populated Session 53). If that secret is rotated, video regeneration fails — document the dependency in the workflow.

3. **Pricing numbers in Scene 14 are frozen as of Session 54.** Any tier price change invalidates the video — rerender. Build a pre-render sanity check that reads `src/lib/payments/tier-config.ts` price fields and warns if they've drifted from the script.

4. **The "twenty-four intelligence engines" claim in Scene 10 is pinned to Session 34 audit.** If engine count changes in a future session, update the script. Otherwise the on-screen artefact (dashboard insight card) won't match the spoken number and agency-reviewer trust breaks.

5. **Achievements count "71" in Scene 11 is pinned to Session 34.** Same drift risk — track it.

6. **Scene 5 voice-conversation demo requires a live /api/ai call during capture.** If the Claude API is rate-limited mid-capture, Scene 5 will fail. Build retry + a fallback pre-recorded conversation snippet for the render.

7. **Scene 15's 2-second final close is tight.** If narration drifts +200ms, the "Both." word lands before the wordmark reveal. The stitcher must ensure frame-perfect sync — use ffmpeg's `-af apad` or `-af atrim` to snap narration to the exact 4:58.0 timestamp.
