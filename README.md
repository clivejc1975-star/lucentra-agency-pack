# Lucentra — first-contact package for partner agencies

This repository is a curated, NDA-gated first-contact mirror prepared for partner-agency conversations. It contains the lightest set of materials needed for an initial discussion: an app overview, a functions summary, a competitive position summary, two concept slides, a five-year forecast, two demo-video scripts plus access instructions, a founder bio, the agency-agnostic outreach email template Clive uses, and a draft mutual NDA.

This is **NOT** the full Lucentra source code. The full repository remains private. Deeper materials (architecture deep-dive, curated source-code mirror, quality dossier, autonomous pipeline production receipts, IP assignment deed template, pilot self-service kit) are available **after** NDA execution and a follow-up call.

> **Link access.** This repository is configured to be readable by anyone with the link — no GitHub login or collaborator invite required. Every file URL below resolves directly for any recipient. Distribute under executed mutual NDA only.
